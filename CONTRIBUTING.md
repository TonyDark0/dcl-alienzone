# Contributing

Thank you for contributing to DCL Alienzone.

1. Open an issue describing the problem, expected result and affected platform.
2. Confirm the change belongs to the MVP in `docs/SCOPE.md`.
3. Create a short-lived branch from `main`.
4. Keep game rules independent from presentation and add tests when applicable.
5. Run `npm run ci` before opening a pull request.

Changes to scoring, the deck, takeover count, networking, parcels, performance budgets or GLB contracts require a recorded decision in `docs/DECISIONS.md`.

Do not include unlicensed material, credentials, wallet keys or personal data.
